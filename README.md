# introai-rps

## Dataset

이 저장소는 Laurence Moroney의 [Rock Paper Scissors Dataset](https://laurencemoroney.com/datasets.html#rock-paper-scissors-dataset)을 사용합니다.
데이터 라이선스는 [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)입니다.

[Hugging Face 배포본](https://huggingface.co/datasets/Javtor/rock-paper-scissors)의
이미지를 300×300에서 32×32 RGB로 축소하고 NumPy `.npz` 형식으로 변환했습니다.
원본의 train/test 구분과 클래스 라벨을 유지했습니다.
